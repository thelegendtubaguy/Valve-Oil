# Translation glossary

Terms Valve Oil UI uses everywhere, so every screen says them the same way. They follow Fluidd's own Spanish and Russian where it has the term. Keep the English wording's plain, short style. Spanish uses `tú` and neutral Latin American and Spanish vocabulary; Russian uses `вы` in lower case.

Stay in English in every language: Valve Oil, Valve Oil UI, Fluidd, Klipper, Moonraker, QIDI, QIDI Box (and Box on its own, as the product's name), QIDI Studio, OrcaSlicer, Spoolman, G-code, `klippy.log` and other file names, macro, command, and object names (`VO_CUT_FILAMENT`, `heater_bed`), and error codes (`QDE_004_008`).

Units of measure stay as symbols in every language: `mm`, `mm/s`, `mm³/s`, `m`, `g`, `KB`, `MB`, `GB`, `Hz`, `°C`, `%`. Units of time are translated, as words would be: Russian `ч`, `мин`, `с`, `д`; Spanish `h`, `min`, `s`.
